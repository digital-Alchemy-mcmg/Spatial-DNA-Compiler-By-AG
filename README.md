## Key Architectural Principles

1. **Deterministic & Offline:** The entire compiler runs locally without cloud services, remote databases, or external APIs.
2. **Zero Hallucination:** Media files (images, audio, video) are never interpreted by AI or OCR; the human user provides the interpretation through the Media Evidence Manifest.
3. **Strict Provenance:** Every atomic claim retains an unbreakable lineage back to its source document, line location, parent employer (`¿`, `¡`), parent section (`¶`, `§`), or Media ID (`MED-{uid}`). Media blurbs carry `citation: null`.
4. **No Content Deduplication:** Repeated skills, responsibilities, or credentials across employers or documents are preserved as distinct, independently retrievable atomic records. (Subject to Operator Contradiction C).
5. **Continuous UID Progression:** Atomic UIDs progress sequentially (`001`, `002`, `003`...) across the entire Document Twin without restarting.
6. **Single-Person Corpus Boundary:** A workbook and evidence directory represents exactly one candidate; person identity mismatches trigger fatal corpus quarantine.
